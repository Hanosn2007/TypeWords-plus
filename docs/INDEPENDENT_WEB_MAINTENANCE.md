## 布局

- 页面宽度基于侧栏外的可用区域，补齐 flex 子项的最小宽度约束。
- 首页任务区与统计在窄窗口改为上下排列，操作按钮可换行。
- 练习底栏按钮换行，收起距离依据实际高度；侧栏在空间不足时显示弹层，宽屏侧栏宽度受屏幕剩余空间限制。
- 弹窗限制视口宽高并可滚动；设置弹窗与设置页在窄屏改为横排分类。
- 单元词表、升级提示、收藏提示、输入区和小浮层补齐宽度限制。
