2026-09-22。本地候选版，基于 `3c62074` 的未提交工作区。**未上线、未推送，未操作正式网站的学习数据。** 周期服务器/Mac备份保持关闭。

## 已实现

- 统一 `/account-data`，原 `/cloud-login` 兼容，旧登录/用户/会员页转到本站入口；设置页不再另有导入和同步实现。
- JSON/ZIP、旧完整备份、旧恢复记录、升级原件及双方比较文件统一解析。先校验/预览，确认后单一IndexedDB事务提交当前数据、附件和待比较标记；内存只在提交后更新。缺附件、未来版本、损坏单元任务均拒绝替换。
- 恢复先落本机，离线可用；云端需要再次比较。CAS版本冲突人工处理，未知旧请求先查回执，恢复标记阻止旧内容自动重放。
- 北京时间每日只留最新一份。本机默认3个有效日期，可调1–30；云端3个。无变化不增加日期，离线中间日期只留本机。手动删除仅影响所选来源，24小时撤销；同日新副本和日期配额受保护。
- 旧历史只读登记，转换失败原件可导出。首次升级不批量删除旧原件。已有附件保守保留，未新增周期压缩或逐键全量历史。
- 读取损坏/更新格式的本机数据时暂停启动保存和同步，提供原始记录及附件导出。
- 退役旧上游账号、Supabase后台读写/回退链路、VS Code客户端及专属工作流。只保留用户主动的旧Supabase只读迁移与公共词典查询。移除的源码已移至废纸篓，忽略的运行数据未动，Git旧版本仍在。

## 用户验收入口

本地：`http://127.0.0.1:4199/account-data`。浏览器内只有合成数据，测试账号为 `account-acceptance@example.test`，与正式账号独立。测试服务数据位于 `output/acceptance/account-data`，日志 `output/account-preview.log`。

1. 在账号与数据页导出ZIP，再导入同一文件，检查预览中的词书与未完成轮次；可以取消，不必替换。
2. 本机历史选择“预览恢复”，确认文字是否清晰。按既定规则，同一天较旧状态不另存。
3. 删除一份测试历史，再撤销，确认当前学习进度不变。
4. 回到单词页，继续“验收用单元词书”Lesson 1；切到Lesson 2后再切回来，查看原任务是否续接。
5. 体验正常打字、删除、切换窗口以及账号与数据页在常用缩放下的布局。

## 边界

- 这不是全站UI重构，也没有改变FSRS算法。视觉、听感、输入手感和真实物理多设备/长期离线仍需用户验收。
- 自定义文章本机音频随完整ZIP导出/导入；云端服务仍不上传该音频，页面会说明限制，本机保存不被连带阻断。
- 浏览器清除存储、损坏磁盘、强杀进程等不等于可保证恢复；普通关闭时仍沿用浏览器原生未保存提示。历史的保存日期不代表其中进度实际发生的日期。
- 生产发布需单独授权；届时重新备份最新浏览器进度和服务器SQLite，不使用测试库。Git回退不回退学习数据库。
