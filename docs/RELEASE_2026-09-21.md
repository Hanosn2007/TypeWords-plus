# 2026-09-21 单元学习版本

源码标签：`release/2026-09-21`；上一上线源码：`release/2026-09-16`。标签保存代码历史，不包含学习数据库，也不会自动回退用户数据。

本版提供按单元独立续学、独立单元词表浏览、正式与自由练习隔离，并修复未选中词书显示零进度。学习规划提取到共享业务模块，保留现有页面风格；并非完整前后端重写。

旧任务首次升级需用户点击“保存副本并更新”。本地副本与新格式写入同一事务；服务器在账号升级后拒绝旧客户端读写。切回旧 Git 代码不会让它重新获得新格式数据的写入权限；再次发布旧代码需要评估格式兼容，不能通过恢复旧数据库解决。

发布前完成 106 项核心测试、Go 测试与 vet、Nuxt/VS Code Web 构建，以及隔离浏览器的升级、续学、结算、自由练习和同步流程。全量类型检查仍有 101 条既有诊断，逐项比较无新增；不宣称全仓类型检查通过。跨物理设备、长期离线和输入手感由实际使用继续验收。

本次发布操作另存本机 IndexedDB、云端快照和服务器 SQLite 备份，并在独立数据库副本上检查恢复及新 API。备份不进入 Git。定时服务器/Mac 备份保持关闭。实际部署结果及哈希记录于私有 `output/releases/20260921T140808Z/`；早期本地验收过程见 `UNIT_REFACTOR_ACCEPTANCE.md`。
